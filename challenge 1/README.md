## 🧠 What I Practiced

- **Stateful vs Stateless** basics and when to extract widgets.
- **Layout fundamentals:** `Row`, `Column`, `Expanded`, `GridView`.
- **Visual hierarchy:** padding, spacing, font weights, and sizes.
- **Theme discipline:** colors, text styles, and reusability.

---

## 🔧 Tech Notes (snapshot)

- **Framework:** Flutter
- **UI:** Material 3 mindset, card-based layout
- **Widgets used:** `Scaffold`, `AppBar`, `GridView`, `Container`, `Image.asset`, `Text`, `IconButton`

## ✍️ Reflection

This is a **foundation**, not perfection. Small visual tweaks (padding, radius, line height) made big differences.  
Main win: confidence navigating the widget tree and keeping code readable.
